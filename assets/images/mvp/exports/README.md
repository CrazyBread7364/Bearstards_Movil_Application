# Exportaciones del icono de Bearstards

`app_icon_master.png` es el archivo fuente. No se debe escalar desde una exportación pequeña.

- `android/` contiene 48, 72, 96, 144, 192 y 512 px para recursos de launcher y tienda.
- `ios/` contiene los tamaños de uso habitual para `AppIcon.appiconset`, incluido el recurso de 1024 px para App Store.

La ilustración para la pantalla de inicio está en `../splash_bearstards.png`.
